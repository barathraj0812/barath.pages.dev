Interactive Mathematics · Conic Sections · JEE Tool

Hyperbola Calculator

An interactive workbench for hyperbolas, built around the JEE Main & Advanced syllabus. Enter a standard, translated, general or rotated equation and it classifies the conic, computes its geometry in exact and decimal form, and plots it on a graph you can pan, zoom and inspect point by point.

JavaScriptCanvas API Exact & Decimal MathsPointer & Touch Input LocalStorageNo Backend

Engineering Highlights

Equation parser for translated, general and rotated (xy-term) conics, with plain-language error messages
Exact fractions and surds alongside configurable-precision decimals
Interactive JEE tools — tangents, normals, polar, chords, diameters, reflection — constructed live on the graph
P (a point on the curve) and Q (a free point) kept in sync between the graph and the inputs
Laboratory for parameter sliders, midpoint locus and answer verification, plus step-by-step derivations
Presentation mode for classroom use, with mouse, touch and pen input

Interactive Mathematics · Conic Sections · JEE Tool

Ellipse Calculator

The ellipse counterpart to the Hyperbola Calculator, built around the JEE Main & Advanced syllabus. It reads standard, translated, general and rotated equations, works out the full geometry in exact and decimal form, and plots it on an interactive graph alongside the auxiliary and director circles, area and perimeter.

JavaScriptCanvas API Exact & Decimal MathsPointer & Touch Input LocalStorageNo Backend

Engineering Highlights

Parser for translated, general and rotated (xy-term) ellipses, with the circle case handled explicitly
Exact fractions and surds alongside configurable-precision decimals
Interactive JEE tools — tangents, normals, chords, focal chord, polar, diameters, reflection — constructed live on the graph
P (a point on the ellipse, set by eccentric angle θ) and Q (a free point) synced between graph and inputs, both draggable
Auxiliary, inner and director circles, plus area and a Ramanujan perimeter approximation
Laboratory, step-by-step derivations and a searchable formula sheet, with a presentation mode for the classroom
